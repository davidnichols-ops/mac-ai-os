# Mac AI OS

A local-first AI operating system for macOS.

## Overview

MAOS is a personal, local-first agent OS. It runs on your Mac, keeps models and
data on-device by default, and exposes its capabilities through a CLI, an MCP
server, and a composable Python runtime.
